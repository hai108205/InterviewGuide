## Hướng dẫn nhập môn

Nếu bạn hỏi tôi trong 3 năm qua điều đúng đắn nhất tôi từng làm là gì? Tôi nghĩ đó là **mua sách và đọc sách**.

Một bài viết điểm lại tất cả những cuốn sách hay mà A Tú đã đọc từ khi học Khoa học Máy tính đến nay, đây có thể coi là toàn bộ thu hoạch và tổng kết trên hành trình tự học của tôi.

![](http://oss.interviewguide.cn/img/202205220026594.jpg)

Sách kinh điển luôn xứng đáng để đọc đi đọc lại nhiều lần, ví dụ như **《Thấu hiểu sâu sắc Hệ thống Máy tính》(CS:APP)** hay cuốn **《Thiết kế ứng dụng chuyên sâu về dữ liệu》(DDIA)**.

Bản PDF điện tử miễn phí của các đầu sách này được lưu trữ tại kho: https://github.com/forthespada/CS-Books

## 1. C++
- **《C++ Primer (5th Edition)》**: Cuốn "kinh thánh" của C++, dày khoảng 800 trang, tôi đã đọc 2 lần, cực kỳ xuất sắc!
- **Bộ 3 Effective**: 《Effective C++》, 《More Effective C++》, 《Effective STL》 của Scott Meyers.
- **《Phân tích mã nguồn STL》(STL Source Code Analysis)** của thầy Hầu Tiệp: "Trước mặt mã nguồn, không có gì là bí mật".
- **《Mô hình đối tượng C++ chuyên sâu》(Inside the C++ Object Model)** của Stanley B. Lippman: Điểm nhấn là chương về hàm ảo (Virtual Functions).
- **Bộ C++ nâng cao**: 《Tối ưu hóa hiệu năng C++》, 《Thiết kế và Tiến hóa ngôn ngữ C++》, 《C++ Ruminations》, 《C++ Template Metaprogramming》.

## 2. Java
- **Nhập môn**: 《Dòng mã Java đầu tiên》, 《Head First Java》.
- **Cốt lõi**: 《Java Cốt lõi Tập 1 (Core Java Volume I)》, 《Effective Java》.
- **Nâng cao**: 《Thấu hiểu sâu sắc Máy ảo Java (Inside JVM)》, 《Lập trình đồng thời Java thực chiến (Java Concurrency in Practice)》, 《Nghệ thuật lập trình đồng thời Java》.

## 3. Python
- **Cơ bản**: 《Fluent Python》, 《Python Cookbook》, 《Python Crash Course》.
- **Web Scraping (Crawler)**: 《Python 3 Phát triển Crawler mạng thực chiến》, 《Tinh thông Scrapy Framework》.
- **Phân tích dữ liệu**: 《Phân tích dữ liệu với Python (Python for Data Analysis)》 của Wes McKinney, 《Phân tích dữ liệu lớn tài chính với Python》.
- **Machine Learning & AI**: 《Collective Intelligence》, 《Machine Learning (Sách Quả Dưa Hấu)》 của Châu Chí Hoa, 《Phương pháp Học thống kê》 của Lý Hàng.

## 4. Ngôn ngữ C
- **《Ngôn ngữ lập trình C》(The C Programming Language - K&R)**: Tác phẩm của Dennis Ritchie (cha đẻ C), cuốn sách nhập môn 9.4 điểm trên Douban.
- **《C Primer Plus》**: Cẩm nang chi tiết và toàn diện về C.
- **Bộ nâng cao về con trỏ và chuyên sâu**: 《C và Con trỏ (Pointers on C)》, 《Chinh phục con trỏ C》, 《Lập trình C chuyên sâu (Expert C Programming)》, 《C Traps and Pitfalls》.

## 5. Ngôn ngữ Go (Golang)
- 《Go in Action》, 《Go Concurrent Programming in Practice (2nd Edition)》, 《Go Web Programming》, 《Advanced Go Programming》.

## 6. Cấu trúc dữ liệu & Thuật toán
- **Nhập môn**: 《Đại thoại Cấu trúc dữ liệu》, 《Aha! Thuật toán》, 《Truyện tranh thuật toán》.
- **Luyện thi tuyển dụng**: 《Kiếm Chỉ Offer》, 《Cẩm nang phỏng vấn mã nguồn lập trình viên (Tả Trình Vân)》.
- **Nâng cao**: 《Programming Pearls (Châu ngọc lập trình)》, 《Vẻ đẹp của lập trình》, 《Thử thách lập trình thi đấu (Competitive Programming)》.
- **Kinh điển**: 《Algorithms (4th Edition) - Robert Sedgewick》, 《Introduction to Algorithms (CLRS)》.

## 7. Hệ điều hành
- 《Thấu hiểu sâu sắc Hệ thống Máy tính (CS:APP)》
- 《Hệ điều hành hiện đại (Modern Operating Systems) - Tanenbaum》
- 《Hệ điều hành hiện đại: Nguyên lý và Hiện thực hóa (ĐH Giao thông Thượng Hải - Trần Hải Ba)》
- 《Tự tay làm Hệ điều hành trong 30 ngày》

## 8. Mạng máy tính
- 《Minh họa trực quan HTTP (Illustrated HTTP)》, 《Minh họa trực quan TCP/IP》
- Bộ 3 cuốn: 《Máy tính hoạt động như thế nào?》, 《Chương trình hoạt động như thế nào?》, 《Mạng hoạt động như thế nào?》
- 《Mạng máy tính: Cách tiếp cận từ trên xuống (Computer Networking: A Top-Down Approach)》
- 《TCP/IP Tường giải Tập 1: Giao thức (TCP/IP Illustrated, Vol 1)》

## 9. Linux & Lập trình mạng
- 《Giáo trình Linux của Chú Điểu (Bird's Linux Private Dishes)》
- 《Lập trình mạng TCP/IP (TCP/IP Network Programming - Yoon Sung-woo)》
- 《Lập trình máy chủ Linux hiệu năng cao (Du Song)》
- 《Lập trình máy chủ đa luồng Linux (Trần Thạc)》
- **Bộ 3 Unix của W. Richard Stevens**: 《UNIX Network Programming (Tập 1 & 2)》, 《Advanced Programming in the UNIX Environment (APUE)》
- 《Thấu hiểu sâu sắc Nhân Linux (Understanding the Linux Kernel - 3rd Edition)》

## 10. Cơ sở dữ liệu
- 《MySQL Bắt buộc phải biết (MySQL in 10 Minutes)》
- 《MySQL hoạt động như thế nào?》, 《High Performance MySQL》, 《Bên trong công nghệ MySQL: InnoDB Storage Engine》
- 《Thiết kế và Hiện thực hóa Redis》, 《Redis thực chiến》
- 《Hiện thực hóa Hệ thống Cơ sở dữ liệu (Database Systems Implementation)》

## 11. Kỹ năng mềm cho Lập trình viên
- 《Kỹ năng mềm: Cẩm nang sinh tồn ngoài code (Soft Skills) - John Sonmez》
- 《Nghệ thuật giao tiếp (The Art of Communicating)》
- 《Tư duy như một lập trình viên (Think Like a Programmer)》
- 《Lập trình viên thực dụng (The Pragmatic Programmer)》
- 《Thần thoại tháng người (The Mythical Man-Month) - Fred Brooks》
- 《Hacker & Họa sĩ (Hackers & Painters) - Paul Graham》
- 《Tư duy phát triển (Mindset: The New Psychology of Success) - Carol Dweck》

## 12. Backend & Thiết kế Hệ thống
- 《Code: Ngôn ngữ ẩn giấu sau phần cứng và phần mềm máy tính (Charles Petzold)》
- 《Tu dưỡng của Lập trình viên: Biên dịch, Liên kết và Thực thi》
- 《Cấu trúc và Diễn giải Chương trình Máy tính (SICP)》
- 《Thiết kế ứng dụng chuyên sâu về dữ liệu (Designing Data-Intensive Applications - DDIA)》
- 《Kiến trúc kỹ thuật Website quy mô lớn (Large Scale Web Architecture)》
- 《Các mẫu thiết kế kiến trúc Microservices (Microservices Patterns - Chris Richardson)》

## 13. Frontend
- 《JavaScript Nâng cao (JavaScript for Professional Web Developers - 4th Edition)》 - "Kinh thánh" của JS
- Bộ sách 《Bạn chưa biết JavaScript (You Don't Know JS - 3 tập)》
- 《Bí mật CSS (CSS Secrets - Lea Verou)》
- 《Vue.js thực chiến》

## 14. Sách thư giãn & Đời sống
- Tác phẩm của Dư Hoa: 《Sống》, 《Hứa Tam Quan bán máu》, 《Huynh đệ》
- Tác phẩm của Lộ Dao: 《Thế giới bình dị》, 《Nhân sinh》
- Hồi ký & Tiểu sử: 《Tiểu sử Mao Trạch Đông》, 《Tiểu sử Steve Jobs》, 《Tiểu sử Che Guevara》, 《Tiểu sử Napoleon》
- Lịch sử: 《Những chuyện thời Minh (Minh triều những chuyện kể)》, 《Năm Vạn Lịch thứ mười lăm》
