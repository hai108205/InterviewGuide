### 3. Trọn bộ câu hỏi phỏng vấn ByteDance (E-commerce Backend)

#### Vòng 1 (80 phút):
- Mã hóa HTTPS, Tính bình đẳng / Bất biến (Idempotency) trong HTTP POST.
- Bảng phân vùng chỉ mục (Clustered vs Non-clustered Index) trong MySQL; Viết truy vấn phân trang sắp xếp.
- Cơ chế MVCC, cấu trúc `LinkedHashMap` triển khai LRU Cache.
- **Thuật toán**: Đảo ngược từng từ trong chuỗi với bộ nhớ phụ `O(1)`, Bài toán 8 quân hậu (Eight Queens Puzzle).

#### Vòng 2 (130 phút - Phỏng vấn chuyên sâu từng chi tiết):
- Cấu trúc Stack Frame trong JVM, điều kiện trở thành GC Roots, bộ nhớ Java Memory Model (JMM).
- Cơ chế phá vỡ mô hình Parent Delegation (Đại biểu phụ huynh) trong Java ClassLoader.
- Phân tích luồng thực thi hàm `put()` trong `HashMap` và tại sao xảy ra Infinite Loop / Deadlock trong đa luồng khi mở rộng dung lượng (Resizing).
- Nguyên lý AQS (AbstractQueuedSynchronizer) đảm bảo tính tái nhập (Reentrancy) của Khóa ReentrantLock.
- Thiết kế hệ thống: Thiết kế hệ thống bán vé tàu cao tốc chịu tải cao (High Concurrency Ticketing System).
- **Thuật toán (3 bài)**: Độ dài chuỗi con chung dài nhất (LCS), Duyệt cây nhị phân Inorder (Đệ quy + Lặp), LRU Cache.

#### Vòng 3 (70 phút):
- So sánh các mô hình I/O (BIO, NIO, AIO), các tham số cấu hình ThreadPoolExecutor, so sánh `ArrayBlockingQueue` vs `LinkedBlockingQueue`.
- 3 định dạng ghi log của MySQL Binlog (Statement, Row, Mixed).
- Thiết kế hệ thống có tính sẵn sàng cao (High Availability System Design).
- **Thuật toán**: Chuỗi con không lặp lại dài nhất (Longest Substring Without Repeating Characters).
