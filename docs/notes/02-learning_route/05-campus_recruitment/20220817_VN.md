### Tổng hợp câu hỏi 4 vòng kỹ thuật Feishu (C++ Backend)

#### Vòng 1:
- Con trỏ `const`: Phân biệt `const int* a`, `int* const a`, `int const* a`.
- Smart Pointer trong C++11 (`std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr`), lý do `std::auto_ptr` bị khai tử.
- Giao thức TCP: Bắt tay 3 bước, giải quyết vấn đề dính gói / vỡ gói (Packet Sticky/Splitting).
- Lập trình mạng I/O Multiplexing: So sánh `select`, `poll`, `epoll` (tại sao epoll hiệu quả hơn về mặt I/O).
- Điều kiện dẫn đến Deadlock trong OS.
- **Thuật toán**: Dãy con tăng dài nhất (Longest Increasing Subsequence - LIS), Tìm phần tử lớn hơn đầu tiên bên phải.

#### Vòng 2:
- Vector trong C++: Cơ chế cấp phát vùng nhớ liên tục khi gọi `push_back`.
- Quá trình biên dịch mã nguồn C++ thành file thực thi (Preprocessing -> Compilation -> Assembly -> Linking); so sánh Dynamic Linking vs Static Linking.
- Bố cục bộ nhớ của tiến trình C++ (Stack, Heap, Data, BSS, Text Segment).
- Cơ chế bộ nhớ ảo (Virtual Memory): Trong OS 2GB RAM có cấp phát được mảng 4GB không?
- Xử lý tệp: Một tiến trình gọi `remove` xóa file đang được tiến trình khác ghi dữ liệu thì OS xử lý như thế nào?
- **Thuật toán**: Số lượng đảo lớn nhất (Max Area of Island), Duyệt cây nhị phân từ Inorder và Postorder.

#### Vòng 3:
- Nguyên lý triển khai hàm `std::sort` trong STL (Introsort kết hợp QuickSort, HeapSort và InsertionSort).
- Cấu trúc dữ liệu Cây đỏ đen (Red-Black Tree), các giải pháp giải quyết xung đột trong Bảng băm (Hash Table).
- Tại sao kiến trúc mạng thực tế chuyển từ mô hình 7 tầng OSI sang mô hình 4/5 tầng TCP/IP?
- Quy trình bắt tay mã hóa TLS/SSL trong HTTPS.
- **Thuật toán**: Top K Frequent Elements (QuickSelect & Min-Heap), Merge Sort.

#### Vòng 4 (Cross-interview với Senior Leader):
- Các System Call được gọi tuần tự từ khi Server khởi tạo Socket đến khi đóng kết nối (`socket`, `bind`, `listen`, `accept`, `read/write`, `close`).
- Bản chất `epoll`: LT (Level Triggered) vs ET (Edge Triggered).
- Phân biệt Kernel Mode vs User Mode; chi phí chuyển đổi ngữ cảnh.
- Viết câu lệnh SQL lấy hàng có giá trị lớn thứ K.
- **Câu đố tư duy logic**: Bài toán chuột thử thuốc độc (Poisoned Wine & Mice Puzzle).
