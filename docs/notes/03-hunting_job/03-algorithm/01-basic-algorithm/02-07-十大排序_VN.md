## Sắp xếp Vun đống (Heap Sort)

Tài liệu video tham khảo chất lượng:
1. [Heap Sort (Bilibili)](https://www.bilibili.com/video/BV1Eb41147dK)
2. [10 phút làm chủ Heap Sort (Bilibili)](https://www.bilibili.com/video/BV1vt4y1y7wR)

### Tư tưởng Thuật toán:
1. Xây dựng **Max-Heap (Đống cực đại)**: Duyệt từ nút không phải lá cuối cùng ($i = (n-2)/2$) ngược lên gốc $0$, gọi hàm `heapify` để đảm bảo nút cha luôn lớn hơn hoặc bằng các nút con.
2. Sắp xếp: Hoán đổi phần tử gốc $nums[0]$ (lớn nhất) với phần tử cuối cùng $nums[n-i-1]$, sau đó thu nhỏ kích thước đống đi 1 và gọi lại `heapify(nums, n - i - 1, 0)` tại gốc.
3. Lặp lại quá trình trên cho đến khi toàn bộ mảng được sắp xếp xong.

### Mã nguồn C++

```cpp
#include <iostream>
#include <vector>

using namespace std;

// Hàm vun đống (Heapify) cho nút thứ i trong cây kích thước n
void heapify(vector<int>& nums, int n, int i) {
    int largest = i;
    int l = i * 2 + 1; // Con trái
    int r = i * 2 + 2; // Con phải

    if (l < n && nums[l] > nums[largest]) largest = l;
    if (r < n && nums[r] > nums[largest]) largest = r;

    if (largest != i) {
        swap(nums[i], nums[largest]);
        heapify(nums, n, largest); // Đệ quy vun tiếp cây con bị ảnh hưởng
    }
}

// Hàm xây dựng Max-Heap từ mảng ban đầu
void heapify_build(vector<int>& nums, int n) {
    int temp = (n - 2) / 2;
    for (int i = temp; i >= 0; i--) {
        heapify(nums, n, i);
    }
}

// Hàm thực thi Heap Sort
void heapSort(vector<int>& nums) {
    int n = nums.size();
    heapify_build(nums, n);
    for (int i = 0; i < n; i++) {
        swap(nums.front(), nums[n - i - 1]);
        heapify(nums, n - i - 1, 0);
    }
}
```
