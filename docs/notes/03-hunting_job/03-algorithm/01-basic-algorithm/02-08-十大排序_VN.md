## Sắp xếp Đếm (Counting Sort)

Sắp xếp đếm thống kê số lượng các phần tử nhỏ hơn hoặc bằng phần tử hiện tại để xác định vị trí chính xác của phần tử đó trong mảng đích.
- Thuật toán dựa trên giả định các phần tử cần sắp xếp đều là **số nguyên không âm** nằm trong một khoảng giới hạn $[0, k]$.
- Nếu $k$ (giá trị lớn nhất) quá lớn, bộ nhớ sẽ phình to. Thích hợp nhất cho các tập dữ liệu có giá trị nằm trong khoảng nhỏ ($0$ đến $1000$).
- Không phải thuật toán dựa trên phép so sánh (Non-comparison Sort) nên tốc độ có thể đạt tuyến tính $O(n + k)$.

### Tư tưởng Thuật toán:
1. Tìm giá trị lớn nhất và nhỏ nhất trong mảng.
2. Đếm số lần xuất hiện của từng giá trị $i$, lưu vào mảng `count[i]`.
3. Tính tổng dồn (Prefix Sum) trên mảng đếm: `count[i] += count[i - 1]`.
4. Duyệt ngược từ cuối mảng ban đầu và điền từng phần tử vào mảng kết quả: `output[--count[nums[i]]] = nums[i]`.

### Mã nguồn C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

void CountSort(vector<int>& vecRaw, vector<int>& vecObj) {
    if (vecRaw.empty()) return;

    int vecCountLength = (*max_element(begin(vecRaw), end(vecRaw))) + 1;
    vector<int> vecCount(vecCountLength, 0);

    // 1. Thống kê tần suất xuất hiện
    for (int i = 0; i < vecRaw.size(); i++)
        vecCount[vecRaw[i]]++;

    // 2. Tính tổng dồn tần suất
    for (int i = 1; i < vecCountLength; i++)
        vecCount[i] += vecCount[i - 1];

    // 3. Đặt phần tử vào vị trí đích (duyệt ngược để giữ tính ổn định)
    for (int i = vecRaw.size(); i > 0; i--)
        vecObj[--vecCount[vecRaw[i - 1]]] = vecRaw[i - 1];
}

int main() {
    vector<int> vecRaw = { 0, 5, 7, 9, 6, 3, 4, 5, 2, 8, 6, 9, 2, 1 };
    vector<int> vecObj(vecRaw.size(), 0);

    CountSort(vecRaw, vecObj);

    for (int x : vecObj) cout << x << " ";
    cout << endl;

    return 0;
}
```
