## Sắp xếp Cơ số (Radix Sort)

Sắp xếp cơ số là thuật toán sắp xếp đa từ khóa (Multi-key Sort), thường được cài đặt dựa trên Sắp xếp Đếm hoặc Sắp xếp Thùng.

### Tư tưởng Thuật toán:
1. Tìm số lớn nhất trong mảng và tính tổng số chữ số $d$ của nó.
2. Bắt đầu từ chữ số hàng đơn vị (hàng thấp nhất - LSD), gom các phần tử vào 10 thùng (từ 0 đến 9) dựa trên giá trị chữ số đó.
3. Thu gom các phần tử từ thùng về mảng theo thứ tự giữ nguyên tính ổn định.
4. Tiếp tục lặp lại quá trình trên cho các chữ số hàng chục, hàng trăm... cho đến hàng cao nhất $d$.

### Mã nguồn C++

```cpp
#include <iostream>
#include <vector>

using namespace std;

// Hàm phụ trợ tìm số chữ số lớn nhất trong mảng
int maxbit(int data[], int n) {
    int maxData = data[0];
    for (int i = 1; i < n; ++i) {
        if (maxData < data[i])
            maxData = data[i];
    }
    int d = 1;
    int p = 10;
    while (maxData >= p) {
        maxData /= 10;
        ++d;
    }
    return d;
}

// Thuật toán Sắp xếp Cơ số
void radixsort(int data[], int n) {
    int d = maxbit(data, n);
    int *tmp = new int[n];
    int *count = new int[10];
    int i, j, k;
    int radix = 1;

    for (i = 1; i <= d; i++) { // Thực hiện d lần sắp xếp
        for (j = 0; j < 10; j++)
            count[j] = 0; // Xóa mảng đếm

        for (j = 0; j < n; j++) {
            k = (data[j] / radix) % 10; // Lấy chữ số tương ứng
            count[k]++;
        }

        for (j = 1; j < 10; j++)
            count[j] = count[j - 1] + count[j]; // Tính tổng dồn vị trí

        for (j = n - 1; j >= 0; j--) {
            k = (data[j] / radix) % 10;
            tmp[count[k] - 1] = data[j];
            count[k]--;
        }

        for (j = 0; j < n; j++)
            data[j] = tmp[j];

        radix = radix * 10;
    }

    delete [] tmp;
    delete [] count;
}
```
