## Sắp xếp Chèn (Insertion Sort)

Sắp xếp chèn xây dựng dần mảng kết quả bằng cách chèn từng phần tử vào vị trí chính xác trong dãy con đã được sắp xếp trước đó.
Ban đầu dãy con có 1 phần tử đầu tiên. Việc so sánh bắt đầu từ cuối dãy con có thứ tự ngược dần về trước; nếu phần tử cần chèn nhỏ hơn thì tiếp tục dịch các phần tử lớn hơn sang phải cho đến khi tìm được vị trí chèn thích hợp.

Nếu gặp phần tử có giá trị bằng nhau, phần tử mới sẽ được chèn ngay phía sau phần tử bằng nó. Do đó thứ tự tương đối ban đầu không bị thay đổi $\implies$ **Sắp xếp Chèn là THUẬT TOÁN ỔN ĐỊNH (Stable)**.

![](./picture/202205072324366-20250322192246839.png)

### Các bước thực hiện:
1. Coi phần tử đầu tiên là dãy đã có thứ tự.
2. Lấy phần tử tiếp theo, duyệt lùi trong dãy đã sắp xếp từ sau ra trước.
3. Nếu phần tử đã sắp xếp lớn hơn phần tử mới, dịch phần tử đó sang phải 1 vị trí.
4. Lặp lại bước 3 cho đến khi tìm thấy phần tử nhỏ hơn hoặc bằng phần tử mới.
5. Chèn phần tử mới vào vị trí trống vừa tạo.
6. Lặp lại các bước 2 đến 5 cho đến hết mảng.
7. **Độ phức tạp**: Thời gian $O(n^2)$, Không gian $O(1)$, Ổn định, Sắp xếp tại chỗ (In-place).

### Mã nguồn C++

```cpp
void insertionSort(vector<int>& a, int n) {
    for (int i = 1; i < n; ++i) {
        if (a[i] < a[i - 1]) {
            int j = i - 1;
            int x = a[i];
            while (j >= 0 && x < a[j]) {
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = x;
        }
    }
}
```
