## Sắp xếp Shell (Shell Sort)

Sắp xếp Shell là một biến thể cải tiến của Sắp xếp Chèn (Insertion Sort). Cả Sắp xếp Chèn lẫn Sắp xếp Nổi bọt đều có nhược điểm: nếu phần tử lớn nhất nằm ở ngay vị trí đầu tiên, cần tới $n - 1$ lần dịch chuyển liền kề mới đưa được về đúng vị trí cuối.

Sắp xếp Shell khắc phục điều này bằng cách chia mảng thành các nhóm con gồm các phần tử cách nhau một bước nhảy $gap$ và thực hiện sắp xếp chèn trên từng nhóm con đó. Ban đầu $gap = n / 2$, sau đó thu hẹp dần $gap = gap / 2$ cho đến khi $gap = 1$ (khi đó toàn bộ mảng đã gần như có thứ tự và chỉ cần rất ít thao tác chèn để hoàn tất).

### Mã nguồn C++

```cpp
#include <iostream>
#include <vector>

using namespace std;

void shellSortCore(vector<int>& nums, int gap, int i) {
    int inserted = nums[i];
    int j;
    // Chèn phần tử vào đúng vị trí trong nhóm con cách nhau khoảng gap
    for (j = i - gap; j >= 0 && inserted < nums[j]; j -= gap) {
        nums[j + gap] = nums[j];
    }
    nums[j + gap] = inserted;
}

void shellSort(vector<int>& nums) {
    int len = nums.size();
    // Khởi tạo gap bằng nửa độ dài mảng và giảm dần
    for (int gap = len / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < len; ++i) {
            shellSortCore(nums, gap, i);
        }
    }
}
```
