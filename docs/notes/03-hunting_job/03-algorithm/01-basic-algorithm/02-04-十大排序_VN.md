## Sắp xếp Nhanh (Quick Sort)

### Tư tưởng Thuật toán (Chia để trị):
1. Chọn một phần tử làm chốt (Pivot / Key), thường chọn phần tử đầu tiên của đoạn.
2. Phân vùng (Partition): Đưa toàn bộ các phần tử nhỏ hơn chốt về bên trái, các phần tử lớn hơn hoặc bằng chốt về bên phải. Khi đó chốt đã nằm ở đúng vị trí cuối cùng trong mảng đã sắp xếp.
3. Đệ quy thực hiện lại thao tác trên cho 2 đoạn con bên trái và bên phải của chốt cho đến khi mỗi đoạn chỉ còn 1 phần tử.

### Mã nguồn C++ chuẩn:

```cpp
#include <iostream>
#include <vector>

using namespace std;

void quickSort(vector<int>& nums, int low, int high) {
    if (low >= high) return;
    int first = low, last = high;
    int key = nums[first];

    while (first < last) {
        // Quét từ phải sang trái tìm phần tử nhỏ hơn key
        while (first < last && nums[last] >= key) {
            last--;
        }
        if (first < last) nums[first++] = nums[last];

        // Quét từ trái sang phải tìm phần tử lớn hơn key
        while (first < last && nums[first] <= key) {
            first++;
        }
        if (first < last) nums[last--] = nums[first];
    }

    nums[first] = key;

    quickSort(nums, low, first - 1);
    quickSort(nums, first + 1, high);
}
```

### Đặc trưng Thuật toán:
- **Độ phức tạp thời gian**: Trung bình $O(n \log n)$, Trường hợp xấu nhất $O(n^2)$ (khi mảng đã có thứ tự và chốt luôn rơi vào phần tử cực trị).
- **Độ phức tạp không gian**: $O(\log n)$ (bộ nhớ ngăn xếp đệ quy).
- **Tính ổn định**: **Không ổn định (Unstable)**.
