## 1. Tìm các URL trùng nhau giữa 2 tập dữ liệu 5 tỷ URL (Bộ nhớ giới hạn 4GB)

- **Đề bài**: Hai file $A$ và $B$, mỗi file chứa 5 tỷ URL (mỗi URL $\approx 64\text{B}$, tổng dung lượng mỗi file $\approx 320\text{GB}$). RAM giới hạn 4GB. Tìm tập giao các URL trùng nhau.
- **Giải pháp Chia để trị (Divide & Conquer qua Hash Partitioning)**:
  1. Quét file $A$, với mỗi URL tính $i = \text{Hash}(\text{URL}) \pmod{1000}$ rồi ghi vào 1000 file con $a_0, a_1, \dots, a_{999}$ (mỗi file nhỏ chỉ $\approx 300\text{MB}$).
  2. Quét file $B$, áp dụng cùng hàm Hash $\pmod{1000}$ ghi vào $b_0, b_1, \dots, b_{999}$.
  3. Mọi URL giống nhau bắt buộc phải rơi vào đúng cặp file con có cùng chỉ số ($a_i$ và $b_i$).
  4. Lần lượt nạp từng file $a_i$ vào một `HashSet` trong RAM, rồi duyệt file $b_i$ đối chiếu $\rightarrow$ Ghi các URL trùng nhau ra kết quả.

## 2. Tìm Top 100 Từ xuất hiện nhiều nhất trong File 1GB (RAM 1MB)

- **Giải pháp**:
  1. Quét file lớn, phân tán các từ vào 5000 file nhỏ qua công thức $\text{Hash}(word) \pmod{5000}$ (mỗi file $\approx 200\text{KB} < 1\text{MB}$).
  2. Nạp từng file nhỏ vào `HashMap<String, Integer>` trong RAM để đếm tần suất xuất hiện.
  3. Duy trì một **Min-Heap (Đống nhỏ) kích thước 100**:
     - Nếu từ đang xét có tần số lớn hơn phần tử ở đỉnh đống, loại bỏ đỉnh và đẩy từ mới vào, sau đó Heapify lại.
     - Sau khi duyệt qua toàn bộ 5000 file con, 100 phần tử trong Min-Heap chính là **Top 100 từ có tần suất cao nhất**.

## 3. Tìm Địa chỉ IP truy cập nhiều nhất trong ngày từ Tệp Log khổng lồ

- **Giải pháp**:
  1. Lọc các bản ghi trong ngày chỉ định, băm IP vào các file nhỏ theo $\text{Hash}(\text{IP}) \pmod N$.
  2. Dùng `HashMap<String, Integer>` đếm tần suất của từng IP trong file nhỏ, đồng thời duy trì một biến `max_ip` và `max_count` để lưu IP có tần suất lớn nhất.

## 4. Tìm các Số nguyên không trùng lặp trong 250 triệu số nguyên (RAM hạn chế)

- **Phương pháp BitMap 2-Bit**:
  - Dải số nguyên 32-bit có tối đa $2^{32} \approx 4.3\text{ tỷ}$ số.
  - Sử dụng **2 bit** để biểu diễn 3 trạng thái cho mỗi số:
    - `00`: Chưa từng xuất hiện.
    - `01`: Xuất hiện đúng 1 lần (Số không trùng lặp cần tìm).
    - `10`: Xuất hiện từ 2 lần trở lên.
  - Tổng bộ nhớ BitMap cần dùng: $2^{32} \times 2\text{ bits} = 1\text{GB}$ RAM.
  - Duyệt qua 250 triệu số nguyên, cập nhật trạng thái bit tương ứng, cuối cùng quét lại BitMap và xuất tất cả các số có trạng thái `01`.

## 5. Kiểm tra nhanh một Số nguyên có tồn tại trong 4 tỷ Số nguyên không?

- **Phương pháp BitMap 1-Bit**:
  - Dùng $2^{32}\text{ bits} \approx 512\text{MB}$ RAM, khởi tạo toàn bộ bit bằng 0.
  - Nạp 4 tỷ số nguyên, đặt bit tại vị trí tương ứng thành 1 (`bits[num] = 1`).
  - Khi cần kiểm tra số $K$, chỉ việc kiểm tra giá trị `bits[K] == 1` với độ phức tạp $O(1)$.

## 6. Bài toán 1000 Chai nước và 10 Con chuột tìm Chai Độc

- **Giải pháp Mã hóa Nhị phân 10-bit**:
  - $2^{10} = 1024 > 1000 \implies$ Đánh số thứ tự chai nước từ 1 đến 1000 ở dạng nhị phân 10-bit.
  - Chuột thứ $i$ ($0 \le i \le 9$) sẽ uống từ tất cả các chai có bit thứ $i$ mang giá trị 1.
  - Sau 1 tuần, kết quả sống/chết của 10 con chuột trực tiếp ghép thành chuỗi nhị phân chỉ đích danh chai độc.
