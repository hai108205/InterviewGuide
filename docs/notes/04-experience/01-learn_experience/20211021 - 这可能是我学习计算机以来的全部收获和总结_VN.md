Tổng hợp danh mục sách gối đầu giường kinh điển của ngành Khoa học máy tính:

---

### 1. Ngôn ngữ C++ & C
- 《C++ Primer 5th Edition》 & Bộ 3 cuốn 《Effective C++》, 《More Effective C++》, 《Effective STL》
- 《STL Nguyên mã phẫu tích (STL Source Code Analysis)》 & 《Khám phá mô hình đối tượng C++ (Inside the C++ Object Model)》
- ![C++ Primer](http://oss.interviewguide.cn/img/202205220027322.png)
- 《Ngôn ngữ lập trình C (The C Programming Language) - Dennis Ritchie》 & 《C và con trỏ》, 《Chuyên gia C》

### 2. Ngôn ngữ Java & Golang
- 《Core Java (Java Cốt lõi)》 & 《Effective Java》
- 《Hiểu sâu về máy ảo Java (JVM)》 & 《Lập trình đồng thời Java thực chiến》
- 《Go in Action》, 《Go Web Programming》, 《Advanced Go Programming》

### 3. Cấu trúc dữ liệu & Thuật toán
- 《Kiếm chỉ Offer (Sword Offer)》 & 《Cẩm nang phỏng vấn mã nguồn lập trình viên (Tả Trình Vân)》
- 《Thuật toán (Algorithms 4th Edition)》 & 《Giải thuật dẫn luận (CLRS - Introduction to Algorithms)》

### 4. Hệ điều hành & Mạng máy tính
- **CSAPP: 《Computer Systems: A Programmer's Perspective (Thấu hiểu Hệ thống Máy tính)》** - Cuốn sách vàng của mọi lập trình viên.
- 《Hệ điều hành hiện đại (Modern Operating Systems) - Tanenbaum》
- 《Minh họa HTTP》 & 《Minh họa TCP/IP》
- 《Mạng máy tính: Tiếp cận từ trên xuống (Top-Down Approach)》 & 《TCP/IP Illustrated Vol 1》
- 《Lập trình mạng Linux hiệu năng cao (Du Song)》 & Bộ 3 cuốn 《Unix Network Programming (Stevens)》

### 5. Cơ sở dữ liệu & Kiến trúc hệ thống
- 《MySQL vận hành như thế nào?》, 《MySQL hiệu năng cao》, 《MySQL Kỹ thuật nội bộ: InnoDB Engine》
- 《Thiết kế và hiện thực Redis (Redis Design and Implementation)》
- **《Designing Data-Intensive Applications (DDIA - Thiết kế hệ thống dữ liệu chuyên sâu)》** - Kiệt tác kiến trúc phân tán.
- ![DDIA](http://oss.interviewguide.cn/img/202205220033806.png)

### 6. Frontend & Kỹ năng bổ trợ
- 《JavaScript nâng cao (Professional JavaScript for Web Developers)》
- 《Bạn chưa biết gì về JavaScript (You Don't Know JS)》
- 《Clean Code (Mã sạch)》, 《Refactoring (Tái cấu trúc mã nguồn)》, 《The Pragmatic Programmer》
